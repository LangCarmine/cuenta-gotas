Todo lo que hace

Cuenta Gotas, la navaja suiza del color.

Cuentagotas nativo

Usa la API EyeDropper de Chrome para capturar cualquier pixel de la pantalla con precision absoluta.

Paletas automaticas

Cada color capturado genera 10 combinaciones armonicas al instante: complementaria, analoga, triadica, tetradica y mas.

HEX, RGB y HSL

Consulta el color en el formato que necesites y copialo con un solo clic.

Historial persistente

La extension recuerda el ultimo color capturado aunque cierres el popup.

100% local

No hay servidores, no hay telemetria, no hay cuentas. Todo se procesa en tu navegador.

Como instalar

Elige tu navegador. Tarda menos de un minuto.

Microsoft Edge

  1. Descarga el archivo ZIP y descomprimelo en una carpeta.
  2. En la barra de direcciones escribe edge://extensions y pulsa Enter.
  3. Activa el interruptor "Modo para desarrolladores".
  4. Haz clic en "Cargar descomprimido".
  5. Selecciona la carpeta que descomprimiste.
Descargar para Edge

Google Chrome

  1. Descarga el archivo ZIP y descomprimelo en una carpeta.
  2. En la barra de direcciones escribe chrome://extensions y pulsa Enter.
  3. Activa el interruptor "Modo de desarrollador".
  4. Haz clic en "Cargar descomprimida".
  5. Selecciona la carpeta que descomprimiste.

Brave
